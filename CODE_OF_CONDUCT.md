# Code of Conduct

## Our standard

RepoLens aims to be a welcoming, respectful, and constructive open-source project.

Contributors are expected to:

- Be respectful and professional.
- Discuss technical decisions in good faith.
- Give useful, specific feedback.
- Focus criticism on ideas and code, not people.
- Respect different backgrounds and experience levels.

Unacceptable behavior includes harassment, personal attacks, discrimination, threats, or deliberately disruptive conduct.

## Reporting

If you experience or observe unacceptable behavior, contact the project maintainer through the contact information on the repository profile. Please include enough context to understand what happened.

Reports will be handled as privately as practical.

## Scope

This code of conduct applies to project repositories, issues, pull requests, discussions, and other project spaces maintained for RepoLens.
