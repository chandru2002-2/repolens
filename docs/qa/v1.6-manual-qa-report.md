# RepoLens Manual QA Report

## Executive Summary

Overall assessment: **PASS WITH ISSUES**

RepoLens successfully ingests public GitHub repositories and local paths, completes analysis without crashing on a diverse real-world corpus, and produces useful Java/Spring graphs plus honest empty states for specialized diagrams when there is no evidence. It is **not** ready to present as trustworthy architecture intelligence for non-Java stacks or as a polished explorer at tablet/mobile widths.

The highest-impact problems are: (1) `emptyMessage` is overloaded so **non-empty diagrams are hidden** in the UI, (2) **narrow viewports overlay the explorer tree with the graph canvas**, (3) **JPA associations are under-detected** on a canonical Spring sample, and (4) the **inspector reports local variables as fields**. Automated tests passing is not sufficient; several of these bugs are UI/contract mismatches.

No P0 crashes, data corruption, or security exploits were observed in this session. GitLab URLs are correctly rejected. Context Studio is absent from the current UI (as expected after removal).

### Cross-Repository Findings

- Specialized diagrams (Sequence/ER/DFD/Use Case) are **Java/Spring/JPA-shaped**. Other languages get architecture/package graphs only.
- Empty-state copy is reused across languages and over-claims Java concepts.
- Dense graphs lose labels; Fit is effectively required.
- Documentation-only repos look like failed analysis to a first-time user.

### Language-Specific Findings

- **Java/Spring:** Best results; still misses Owner→Pet JPA and pollutes inspector/sequence with tests/locals.
- **JS/TS/Python/Go:** Structural counts look plausible; no web/API/DFD projection from Express/Flask/Gin.
- **Polyglot:** Silent skip, not a structured “unsupported language” report per file.

### Analysis Accuracy

See table above. Highest trust damage: inspector fields and ER missing `Owner.pets`.

### Performance

Small repos are fine. Medium Java graphs complete quickly when cloned. The bottleneck is **rendering and labeling**, not ingest time, for Petclinic/JHipster.

### Most Important Findings (ranked)

1. F-01 emptyMessage hides real diagrams (impact, trust, easy to reproduce, moderate fix)
2. F-02 overlay layout at < desktop width (impact, frequency)
3. A-02 missing JPA associations (trust)
4. A-01 inspector false fields (trust)
5. F-04 concurrent git cache (reliability)

## Recommended Improvements

### P0

None observed.

### P1

- Stop using `emptyMessage` for truncation/advisory notes; show graph + banner (`truncated` already exists).
- Fix explorer/graph/inspector stacking below ~1024px (or declare desktop-only in the UI).
- Do not emit local variables / `null` as fields.
- Serialize git clones per cache directory (or reuse existing clone).

### P2

- Detect `@OneToMany` + `@JoinColumn` without generic type parameters.
- Language-aware empty states (no `@Entity` copy for Flask).
- Humanize errors; strip server paths.
- Clear errors when the user edits the URL; don’t show previous job status.
- Exclude `*Test(s)` from Sequence by default (or a “include tests” toggle).
- Use-case labels from full mapping paths, not last path segment.
- Search: rank types (CLASS) above duplicate fields.

### P3

- Spacing so tabs don’t clip explorer metadata.
- Inspector `CALLS` labels with separators.
- Default Fit after layout.
- Nested class naming in the tree.

### P4

- In-UI legend for each diagram type.
- Show parse engine and language coverage after analysis.
- Docs-only empty state.
- Keyboard pan/zoom and tree navigation.
- Optional AI explanations remain a roadmap item (not implemented; not a regression).
